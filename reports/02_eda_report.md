# บทที่ EDA: การเตรียมข้อมูลและการวิเคราะห์เชิงสำรวจ
### Spatial Probability of Aftershocks Given an Identified Mainshock — Southeast Asia (7 Source Zones)

เอกสารนี้สรุปขั้นตอนการทำความสะอาดข้อมูล การกำหนดขอบเขตแหล่งกำเนิดแผ่นดินไหว (source zones) 7 โซน
และผลการวิเคราะห์เชิงสำรวจ (EDA) เบื้องต้น ก่อนเข้าสู่ขั้นตอนการสร้างแบบจำลองความน่าจะเป็นเชิงพื้นที่ของ aftershock
(สถานะปัจจุบัน: **ทำความสะอาดข้อมูล + EDA เสร็จแล้ว ยังไม่ได้สร้างโมเดล**)

## 2. การทำความสะอาดและรวมข้อมูล (`scripts/01_clean_data.py`)

1. แปลงทั้งสองไฟล์ให้อยู่ใน schema เดียวกัน: `event_id, time_utc, lat, lon, depth_km, mag, mag_type, network, place`
2. กรองแถวที่ไม่มี time/lat/lon/mag หรือพิกัด/ขนาดผิดปกติ (TMD และ USGS ทุกแถวผ่านเกณฑ์นี้ 100%)
3. **Deduplication ระหว่างเครือข่าย**: เหตุการณ์ขนาดใหญ่ในภูมิภาคมักถูกบันทึกซ้ำโดยทั้ง TMD และ USGS
   ใช้เกณฑ์ เวลาต่างกัน ≤60 วินาที และระยะห่าง ≤50 กม. → พบคู่ซ้ำ **1,270 เหตุการณ์** และเก็บฉบับ USGS ไว้
   (เพราะมี magnitude type/QC ที่เป็นมาตรฐานกว่า) ส่วน TMD ที่เหลือคือเหตุการณ์ขนาดเล็กที่ USGS ตรวจไม่พบ
4. ลบแถวซ้ำซ้อนภายในเครือข่ายเดียวกัน (31 แถว)

**ผลลัพธ์:** แคตตาล็อกรวม **62,506 เหตุการณ์** (2007-01-04 – 2026-09-11), M0.6–M8.6
→ `data/processed/catalog_clean.csv`

## 3. การกำหนด 7 Source Zones (`scripts/02_source_zones.py`)

ข้อมูลดิบไม่มีรหัสโซนมาให้ จึงกำหนดขอบเขต **7 โซนเทคโทนิกหลักของเอเชียตะวันออกเฉียงใต้** ขึ้นเองในลักษณะ
"first-order approximation" อ้างอิงแนวคิดทางธรณีแปรสัณฐานทั่วไป (Hall, 2002; Simons et al., 2007
และงานสรุป seismotectonics ของภูมิภาค) โดยใช้เส้นแบ่งเชิงเส้น/กรอบพิกัดอย่างง่าย **เหมาะสำหรับขั้นตอน EDA เท่านั้น**
ก่อนสร้างโมเดลจริงควรปรับปรุงขอบเขตด้วยฐานข้อมูลรอยเลื่อนที่เชื่อถือได้ (เช่น GEM Global Active Faults Database)
หรืออ้างอิง source zonation จากงาน PSHA ที่ธีสิสจะเลือกใช้เป็นทางการ

| รหัส | ชื่อโซน | ลักษณะเทคโทนิก |
|---|---|---|
| Z1 | Sunda Megathrust – Sumatra Segment | รอยเลื่อนมุดตัวนอกชายฝั่งตะวันตกสุมาตรา (interface + outer-rise) |
| Z2 | Great Sumatran Fault Zone | รอยเลื่อนตามแนวระดับ (strike-slip) บนเกาะสุมาตรา |
| Z3 | Sunda Megathrust – Java to Nusa Tenggara | รอยเลื่อนมุดตัวนอกชายฝั่งชวา–นูซาเต็งการา |
| Z4 | Andaman-Nicobar-Myanmar Arc & Sagaing Fault | เขตมุดตัว Indo-Burma, ทะเลอันดามัน, รอยเลื่อน Sagaing (พม่า) |
| Z5 | Shan-Thai / Indochina Intraplate Zone | รอยเลื่อนในแผ่นทวีป: ไทย ลาว กัมพูชา เวียดนาม ยูนนานตอนใต้ |
| Z6 | Philippine Mobile Belt | Philippine Trench/Fault, Manila Trench, แนวชนกันลูซอน–ไต้หวัน |
| Z7 | Sulawesi – Molucca Sea – Banda Arc | เขตชนกันซับซ้อนอินโดนีเซียตะวันออก |

**การตรวจสอบความสมเหตุสมผล (sanity check):** ทดสอบพิกัดเมืองสำคัญ 8 จุด (กรุงเทพฯ, เชียงใหม่, ย่างกุ้ง,
บันดาอาเจะห์, นอกชายฝั่งสุมาตราเหนือ, จาการ์ตา, มะนิลา, มานาโด) — **ผ่านทั้ง 8/8 จุด** หลังปรับขอบเขต
(จาการ์ตาเคยถูกจัดเข้า Z2 ผิดพลาดในรอบแรก แก้ไขโดยจำกัดลองจิจูดของ Z1/Z2 ไม่เกิน 105.5°E)

**ผลการจำแนก (62,506 เหตุการณ์):**

| โซน | จำนวนเหตุการณ์ | สัดส่วน |
|---|---|---|
| Z7 (Sulawesi-Molucca-Banda) | 16,460 | 26.3% |
| Z6 (Philippine Mobile Belt) | 13,435 | 21.5% |
| Z4 (Andaman-Myanmar-Sagaing) | 9,156 | 14.6% |
| Z5 (Shan-Thai/Indochina) | 8,656 | 13.8% |
| Z3 (Java-Nusa Tenggara) | 5,277 | 8.4% |
| Z1 (Sumatra Megathrust) | 3,123 | 5.0% |
| Z2 (Sumatran Fault) | 1,589 | 2.5% |
| **Unclassified** | **4,810** | **7.7%** |

เหตุการณ์ที่ "Unclassified" ส่วนใหญ่อยู่**นอกขอบเขตเอเชียตะวันออกเฉียงใต้**อย่างชัดเจน — หมู่เกาะ Bonin/Ryukyu/Volcano
(ญี่ปุ่น), มณฑลยูนนานตอนใน (จีน), Micronesia, และปาปัวตะวันออกไกล — ซึ่งยืนยันว่าขอบเขต 7 โซนที่กำหนดใช้งานได้ดี
(ไม่ได้ดูดเหตุการณ์นอกภูมิภาคเข้ามาผิดที่) ส่วนที่เหลือเล็กน้อยอยู่บริเวณรอยต่อโซนที่ยังไม่ครอบคลุม 100%

→ `data/processed/catalog_with_zones.csv`, นิยามโซน: `data/processed/source_zone_definitions.csv`

## 4. ผลการวิเคราะห์เชิงสำรวจ (`scripts/03_eda.py`)

### 4.1 แผนที่การกระจายตัวเชิงพื้นที่ — `figures/01_event_map.png`
เห็นรูปแบบส่วนโค้ง (arc) ของแต่ละโซนชัดเจน: แนวทแยง Z1/Z2 ตามเกาะสุมาตรา, แนวโค้ง Z3 ตามร่องลึกชวา,
แถบ Z4 ตามแนวเหนือ-ใต้ของพม่า/อันดามัน, กลุ่ม Z5 บริเวณไทยตอนเหนือ/ตะวันตก, รูปตัว S ของ Z6 ตามฟิลิปปินส์–ไต้หวัน,
และกลุ่มกระจาย Z7 ทางอินโดนีเซียตะวันออก — ยืนยันเชิงภาพว่าขอบเขตที่กำหนดสอดคล้องกับธรณีสัณฐานจริง

### 4.2 Frequency-Magnitude Distribution และ b-value — `figures/02_magnitude_frequency.png`
ประมาณค่า **Mc (magnitude of completeness)** ด้วยวิธี maximum curvature และ **b-value** ด้วย Maximum Likelihood
(Aki/Utsu estimator) รายโซน:

| โซน | Mc | b-value | n (≥Mc) |
|---|---|---|---|
| Z1 | 4.3 | 1.02 ± 0.02 | 2,490 |
| Z2 | 4.3 | 1.09 ± 0.03 | 1,167 |
| Z3 | 4.2 | 1.07 ± 0.02 | 4,405 |
| Z4 | 4.3 | 1.15 ± 0.02 | 2,554 |
| Z5 | 2.4 | **0.54 ± 0.01** | 5,011 |
| Z6 | 4.3 | 1.13 ± 0.01 | 11,123 |
| Z7 | 4.2 | 1.11 ± 0.01 | 13,700 |

โซน Z1, Z3, Z4, Z6, Z7 ได้ b ≈ 1.0–1.15 ซึ่งอยู่ในช่วงปกติของ global average (b≈1.0) ตามที่คาดจากทฤษฎี
Gutenberg-Richter **ยกเว้น Z5 ที่ได้ b=0.54 ต่ำผิดปกติ** — ดูสาเหตุที่เป็นไปได้ในหัวข้อ 5 (ข้อจำกัด)

### 4.3 การกระจายตามเวลา — `figures/03_temporal_distribution.png`
จำนวนเหตุการณ์ต่อปีแยกตามเครือข่าย แสดงให้เห็นว่า TMD เริ่มบันทึกน้อยมากช่วง 2007–2011 (เครือข่ายสถานีตรวจวัด
ยังไม่ครอบคลุม) แล้วเพิ่มขึ้นชัดเจนหลัง 2012 และโดยเฉพาะหลัง 2022 — สะท้อนว่า **completeness ของ TMD ไม่คงที่ตามเวลา**

### 4.4 การกระจายตามความลึก — `figures/04_depth_histogram.png`
Z4, Z5 (intraplate) มีความลึกมัธยฐานตื้นมาก (~2–10 กม.) สอดคล้องกับแผ่นดินไหวในเปลือกโลกทวีป
ส่วน Z2, Z3, Z6, Z7 มีพิสัยความลึกกว้างกว่า สอดคล้องกับกิจกรรมของเขตมุดตัว (interface ถึง intermediate-depth)

ตารางสรุปทั้งหมด: `reports/zone_summary.csv`

## 5. ข้อจำกัดของข้อมูลที่ต้องพิจารณาต่อในบทถัดไป

1. **Magnitude scale ไม่เป็นเนื้อเดียวกัน**: TMD รายงาน ML ส่วน USGS ใช้ mb/mww/ml ปะปนกัน — กระทบการคำนวณ
   b-value และ Mc โดยตรง ควรแปลงเป็นมาตราเดียว (เช่น Mw) ด้วยสมการ conversion ก่อนสร้างโมเดลจริง
2. **b-value ผิดปกติของ Z5**: น่าจะมาจาก (ก) completeness ของ TMD ที่เปลี่ยนแปลงตามเวลา (ดูข้อ 4.3)
   ทำให้ FMD ไม่ตรงกฎ power-law ที่ magnitude ต่ำ และ (ข) การปนกันของ ML(TMD) กับ mb/mww(USGS) ในโซนเดียวกัน
   ควรแบ่งวิเคราะห์ตามช่วงเวลา/เครือข่ายแยกกัน หรือใช้ time-varying Mc ในบทถัดไป
3. **ขอบเขต 7 โซนเป็นค่าประมาณอย่างหยาบ** (เส้นตรง/กรอบพิกัด) ไม่ใช่แนวรอยเลื่อนจริง — เหมาะสำหรับ EDA
   แต่ควรทดแทนด้วยข้อมูล fault trace จริงก่อนคำนวณระยะทาง mainshock–aftershock เชิงพื้นที่ในแบบจำลองสุดท้าย
4. **Dedup ระหว่างเครือข่ายเป็น heuristic** (60s/50km) อาจพลาดคู่ซ้ำบางคู่หรือรวมเหตุการณ์ต่างกันที่บังเอิญใกล้กันมาก
5. **7.7% ของข้อมูล unclassified** — ส่วนใหญ่ถูกต้องแล้วที่ควรอยู่นอกขอบเขตศึกษา แต่ควรตรวจสอบซ้ำหากต้องการความครบถ้วน 100%

## 6. ขั้นตอนถัดไป (บทสร้างแบบจำลอง — ยังไม่ได้เริ่ม)

เมื่อ EDA เป็นที่พอใจแล้ว ขั้นตอนถัดไปสำหรับหัวข้อ "spatial probability of aftershock given an identified mainshock"
จะประกอบด้วย:
1. **Mainshock–aftershock declustering**: แยกเหตุการณ์หลัก/ตาม ด้วยวิธีมาตรฐาน เช่น Gardner-Knopoff window,
   Reasenberg (1985), หรือ ETAS-based declustering — ต้องเลือกวิธีและ window parameters ให้เหมาะกับแต่ละโซน
   (เพราะ b-value/ ความหนาแน่นต่างกันมาก)
2. **แบบจำลอง spatial probability**: ตัวเลือกหลักคือ (ก) Omori-Utsu spatial decay kernel
   (density ~ 1/(r+d)^q ตามระยะห่างจาก mainshock), (ข) ETAS spatial kernel เต็มรูปแบบ, หรือ
   (ค) discretize พื้นที่รอบ mainshock เป็นกริด แล้วใช้ logistic regression/ML model โดยมี feature เช่น
   ระยะทาง, มุม azimuth เทียบกับแนวโซน, ความลึก mainshock, และรหัสโซนเป็นตัวแปรอธิบาย
3. **Train/validate แยกตามโซน** เนื่องจาก b-value และความหนาแน่นข้อมูลต่างกันมาก (Z2 มีแค่ 1,589 เหตุการณ์
   เทียบกับ Z7 ที่มี 16,460)
4. ปรับปรุงขอบเขตโซนด้วยฐานข้อมูลรอยเลื่อนจริงตามข้อจำกัดข้อ 3 ข้างต้น
